Rulebook Data Builder

A local, offline helper for typing up your own DCC RPG rulebook transcriptions — not part of the Owlbear Rodeo extension itself, doesn't talk to OBR or the internet at all. Fill in each field from your own copy of the rulebook, then copy or download the JSON at the bottom and paste it into the actual DCC Suite extension's own 📖 Import Rulebook Data popup (Dice tab). Everything you type here stays in this browser tab (and this tab's own local storage) until you export it — nothing is sent anywhere. Picking up a previous session? Load its JSON file below first.
